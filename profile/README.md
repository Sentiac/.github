# Sentiac

**Simplifying Robot Autonomy.** We build software for machines that sense, think and act.

## Products

- **[Simlabs](https://simlabs.sentiac.com)**: robot simulation streamed from the cloud to your browser, so teams can evaluate worlds, controls and robot behaviour without building every simulator locally.
- **[ARC](https://arc.sentiac.com)**: a unified robot autonomy framework covering localization, mapping, planning and control.
- **[Nexus](https://nexus.sentiac.com)**: secure connectivity across robots, machines and industrial systems.

We also provide ROS 2 engineering, simulation and digital-twin work, and systems integration.

## Open source

- [**auto_handeye_calibration**](https://github.com/Sentiac/auto_handeye_calibration): automatic hand-eye calibration for six-axis arms using ROS 2, MoveIt and a ChArUco target (experimental).
- [**BehaviorTree.PY**](https://github.com/Sentiac/BehaviorTree.PY): Python bindings for BehaviorTree.CPP.
